# Sider 1.0.1

Sider 1.0.1 is a language and distribution-policy patch. It preserves the command
subset, RESP2 framing, storage formats, persistence guarantees, and supported targets
from 1.0.0.

## Changes

- Translate runtime errors, diagnostics, tests, tooling output, metadata, and project
  documentation from Brazilian Portuguese to English.
- Rename `PLANO.md` to `PLAN.md` and update all repository references.
- Publish the repository and GitHub release artifacts publicly.
- Keep the crate excluded from crates.io with `publish = false`; no container registry
  publication is introduced.

Human-readable error text is observable and may differ from 1.0.0. Clients should use
RESP error classes and documented command behavior instead of matching complete prose.

## Compatibility and limitations

The Redis reference remains 8.10.1 at the digest recorded in
`releases/plan.json`. Sider still implements RESP2 only, uses fixed shards, limits
transactions and multikey commands to one shard, and provides asynchronous replication
with manual promotion. Authentication, ACLs, TLS, RESP3, Lua, automatic failover,
online resharding, and cross-shard transactions remain out of scope.
